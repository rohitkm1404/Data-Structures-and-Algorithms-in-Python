
# DSA in Python — Goodrich, Tamassia, & Goldwasser

This repo is where I keep all my code and exercise solutions as I read through **Data Structures and Algorithms in Python**.

Rather than relying on built-in tools, I'm writing these data structures from scratch to get a better handle on how memory, recursion, and algorithms actually work under the hood.

---

##  What's Inside

* **Custom ADTs:** My own implementations of stacks, queues, trees, graphs, and search trees using standard OOP practices.
* **Exercise Solutions:** Answers to end-of-chapter problems divided into Reinforcement, Creativity, and Projects.
* **Complexity Notes:** Time and space complexity ($O(n)$) noted down in docstrings for quick reference.
